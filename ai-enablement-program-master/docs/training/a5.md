# A5: AI Value Portfolio And Enablement Dashboard

## Goal

Show value-level thinking: use cases, baseline, cost, risk, metrics and rollout.

## Feature

Add an internal page:

```text
/catalog/enablement
```

## Tasks: Frontend

1. Ask AI to propose a dashboard/content plan before edits. The plan must list UI files, use-case fields, verification commands and risks.

2. Review the plan yourself. Confirm that the content is tied to this catalog training project and does not use real company/customer data.

3. If the plan is correct, explicitly approve implementation and ask AI to add route `/catalog/enablement`.

4. Ask AI to add page:

```text
frontend/src/pages/EnablementDashboardPage.tsx
```

5. Ask AI to show a portfolio table on the page.

6. Ask AI to include at least 5 use cases:
   - Catalog Excel Analysis Assistant;
   - Catalog Import Validation Assistant;
   - MR Review Assistant;
   - Test Gap Analyzer;
   - Catalog Sales Journey Delivery Agent.

7. Ask AI to include these fields for each use case:
   - current process;
   - baseline;
   - pain;
   - AI solution;
   - expected value;
   - cost estimate;
   - risk;
   - data sensitivity;
   - human-in-the-loop;
   - success metrics;
   - pilot owner;
   - status;
   - rollout plan.

8. Run or review frontend checks and inspect the final diff. Confirm that no backend, external integration or sensitive data was added unless explicitly approved.

## Tasks: Documentation

1. Create or ask AI to draft the artifact, then review and correct it yourself:

```text
docs/training/artifacts/a5-ai-use-case-portfolio.md
```

2. In the artifact, add:
   - portfolio table;
   - detailed section per use case;
   - cost-value reasoning;
   - security/privacy risks;
   - success metrics;
   - pilot plan;
   - rollout plan.

## Main Files

- `frontend/src/app/router.tsx`
- `frontend/src/pages/EnablementDashboardPage.tsx`
- `frontend/src/components/*`
- `frontend/src/styles/app.less`
- `docs/training/artifacts/a5-ai-use-case-portfolio.md`

## Not Allowed

- Do not add backend if static content is enough.
- Do not add real company/customer data.
- Do not add external integrations.

## Acceptance Criteria

- `/catalog/enablement` is available.
- The page contains at least 5 use cases.
- Each use case contains the required fields.
- The A5 artifact is created.
- Frontend build passes.

## Checks

```bash
cd frontend
npm test -- --watchAll=false
npm run build
```
