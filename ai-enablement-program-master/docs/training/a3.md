# A3: Channel Availability And Reusable Workflow

## Goal

Make a full-stack change and add a reusable workflow for the selected AI tool.

## Feature

Add the field:

```text
channelAvailability
```

Allowed values:

- `Online`
- `Retail`
- `Call Center`
- `Online,Retail`

## Tasks: End-To-End Field Change

Complete this part as one approved AI-assisted workflow. The student asks for research and a plan first; AI changes files only after the student approves the plan.

### Step 1: Research With AI

1. Ask AI to map the current Excel -> importer -> JSON -> backend -> frontend -> tests flow for catalog fields. Do not allow edits yet.

   Suggested prompt:

```text
Research how a catalog field flows from Excel to generated JSON, backend API, frontend UI and tests.
List the relevant files, data transformation points, generated files and risks.
Do not change files yet.
```

2. Ask AI to propose an implementation plan for `channelAvailability`. The plan must include:
   - Excel column and values;
   - importer normalization rules;
   - generated JSON regeneration command;
   - backend domain/DTO/mapper/filter/metadata changes;
   - frontend API types, badges, filter and details changes;
   - tests and smoke checks;
   - risks and assumptions.

3. Review the plan. Confirm that generated JSON will be regenerated from Excel, not manually edited. If the plan is correct, explicitly approve implementation.

### Step 2: Catalog Data

4. After approval, ask AI to add the `Channel Availability` column to `catalog/mobile-operator-catalog.xlsx`.

5. Ask AI to fill values for different product types:
   - postpaid plans;
   - fiber plans;
   - smartphones;
   - routers;
   - accessories.

6. Ask AI to update the importer:
   - read the field from Excel;
   - normalize the value into a channel list;
   - preserve traceability.

7. Ask AI to regenerate JSON with the import command, then review the generated diff:


### Step 3: Backend

8. Ask AI to implement the approved backend changes:
   - add `channelAvailability` to the domain model;
   - add the field to summary/detail DTOs;
   - update the MapStruct mapper;
   - add filter by channel for `/api/catalog/products`;
   - update metadata available filters;
   - add tests for importer/API/filtering.

### Step 4: Frontend

9. Ask AI to implement the approved frontend changes:
   - update API types;
   - show channel badges on `/shop`;
   - add filter by channel on `/catalog`;

10. Ask AI to run or document catalog import, backend checks and frontend checks.

11. Review the final diff yourself. Confirm that traceability fields remain present, generated JSON came from import, and no A4/A5 or production-integration scope was added.
